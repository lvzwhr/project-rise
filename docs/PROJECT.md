# Project Rise — Combat Validation Demo

只验证动作 RPG 战斗手感，不制作完整游戏。

战斗手感参考《艾尔登法环》：攻击有起手/判定/后摇，体力是核心资源，翻滚有无敌帧，大招有超级装甲，敌人攻击可读、可躲、可罚。

## 成功标准

能在一个小竞技场里，用手柄或键盘完成：

1. 锁定敌人，绕圈走位
2. 轻击连段、重击、蓄力重击、跳跃攻击、奔跑攻击
3. 翻滚（有无敌帧）、格挡、精力耗尽惩罚
4. 被可读的敌人攻击打中 / 躲开 / 硬直打断 / 超甲顶过去
5. 架势条被打空后进入可处决窗口

以上每一项都能用画面和 Debug HUD 看出来，而不是只写在文档里。

## 范围内

- 引擎：**Godot 4.7.2**（本机 `D:\godot\Godot_v4.7.2-stable_win64.exe`），3D + GDScript
- 一个圆形/方形竞技场
- 一名玩家（人形骑士）
- 一类人型敌人（骑士），可选第二类重型敌人
- 战斗 Debug HUD：体力、架势、无敌帧、受击盒开关
- 占位模型和占位特效，只要轮廓、颜色、时间点清楚

## 范围外

开放世界、剧情、背包、养成、多人、坐骑、召唤、复杂战灰、状态异常、过场、完整关卡。

数值只服务手感，不服务成长。
