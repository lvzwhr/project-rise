# 动画时间轴 — 60 FPS，v1 冻结帧

**来源：** `docs/design/player-moveset.md`、`docs/design/enemy-knight.md`。  
**规则：** 帧数照抄，不调。若片段撑不满这些帧，**HOLD 该姿势**。禁止缩短表格。

- 1 帧 = 1/60 s。表格 **从 1 起算**。
- Godot AnimationPlayer：`t = (frame - 1) / 60`，`length = total_frames / 60`。
- `hit_on` = 第一个判定帧。`hit_off` = 最后一个判定帧的下一帧。
- `can_buffer` 在第一个缓冲帧 **触发一次**；标志保持到状态结束。
- 预警 telegraph 列是可读的起手。敌人预警 telegraph 为 **红 `#E03030`**。玩家起手只靠动作（不用敌人红）。
- 根运动距离来自设计表。程序作用在 CharacterBody3D 上。视觉片段可偏移 `Hip` 做读感；它们不是物理。

片段在 `game/assets/animation/`，在 `Visual/AnimationPlayer` 上播放。

## 与设计的冲突 — 未悄悄改

| 条目 | 我做了什么 |

| Slam 地面圆 **1.6 m** vs 砸地命中圆柱 **1.8 m** | 两边都保留。圆是预警 telegraph，不是命中贴花。若试玩误读边缘，设计师可之后放大圆。 |
