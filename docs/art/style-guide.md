# 视觉规范 — 战斗可读性 v1

**状态：** 已与设计冻结。仅占位。好看可选，可读必须。  
**权威来源：** `docs/design/combat-gdd.md` §8、`player-moveset.md`、`enemy-knight.md`。  
**资源：** `game/assets/`。

本 demo 必须在 **12 m**、Debug HUD **关** 时仍可读。颜色与轮廓承担战斗信息。若玩家无法在判定前仅凭姿势 + 颜色说出 Sweep / Thrust / Slam / DoubleSlash，则美术失败。

---

## 1. 轮廓

| 角色 | 身高 | 体量 | 12 m 可读性 |
| --- | --- | --- | --- |
| 玩家骑士 | **1.80 m** | 更瘦的胶囊，肩宽约 0.70 m | 冷钢 / 蓝灰。肢体与剑轮廓清楚。禁止与敌人同色。 |
| 敌人骑士 | **1.95 m** | 更重、肩更厚约 0.90 m | 暗甲 + **红**肩甲 / 布条（左肩）。比玩家更宽，方便 lock-on 辨认目标。 |

共用规则：

- 人形，两腿两臂，**右手**直剑。
- Idle 时左右必须一眼可辨。不要把武器镜像到双手。
- 武器长度按长剑读：刃约 1.10 m（玩家）/ 约 1.25 m（敌人），柄约 0.22 m。设计表里的命中半径（1.6–2.8 m）是 **hitbox**，不是网格缩放。不要把剑拉长去贴 2.8 m 的 Thrust 胶囊。
- 无披风、无布料模拟、无头盔缝隙。头球 + 肩块足够。
- 翻滚轮廓要 **矮**：胯下落，体积始终在画面里。身体不得消失或全透明。
- StanceBroken 是 **跪姿**，武器放下、胸口敞开。必须从 Mid（2.2–3.5 m）读成「可以走进去」，而不是微小后仰。

静止朝向：运行时角色前方在 yaw 0 为 **+Z**（与 `combat_actor.get_forward` 一致）。剑在 **+X**（右手）。

## 2. 色标（禁止混色）

世界色来自 GDD §8 的 hex。用在武器、地面标记、debug 着色和特效上。不要为「更好看」改色相。

| 色标 | Hex | RGB 0–1 | 出现位置 |
| --- | --- | --- | --- |
| 预警 telegraph / 起手 | `#E03030` | `0.878, 0.188, 0.188` | 敌人武器从预警 telegraph f1 起发光。Slam **地面圆** 从 Slam f8 出现。 |
| 判定中 | `#F0D030` | `0.941, 0.816, 0.188` | 武器 / 砸地体积 **仅在 hitbox 开启时**。 |
| 可罚后摇 / 长后摇 / StanceBroken | `#30C060` | `0.188, 0.753, 0.376` | Sweep 从后摇 f8 起绿。Thrust 从后摇 f6 起绿。Slam **整段后摇** 都绿。DoubleSlash 第二击后摇 f8 起绿。StanceBroken 轮廓贯穿全部 90 f。 |
| I-frame debug | `#40A0FF` | `0.251, 0.627, 1.0` | 玩家胶囊可选着色，仅在 `iframe` 开启时。可随 HUD 线框开关关掉。 |
| Hyperarmor debug | `#E07020` | `0.878, 0.439, 0.125` | 可选描边 / 胶囊着色，仅在 `hyperarmor` 开启时。 |
| 受击闪白 | `#FFFFFF` | `1, 1, 1` | 被击中者网格 **恰好 1 帧**（1/60 s）变白。 |

## 3. 战斗色语言（开启时）

| 阶段 | 颜色 | 动作 |
| --- | --- | --- |
| 敌人预警 telegraph | 武器红。Slam 另加地面圆。 | 每招姿势不同（见 §5）。 |
| 判定中 | 打击体积上黄。 | 跟随表中弧线：水平 / 直线 / 砸下 / 两击。 |
| 可罚后摇 | 武器绿或短暂绿描边。 | 胸口敞开、刃偏离中线；Slam 时膝盖弯曲。 |
| 玩家 i-frame | 仅 debug 蓝。翻滚保持可见的蹲走。 | 不要藏网格。 |
| Hyperarmor | Debug 橙。 | 重击蓄力 / Slam 举臂仍要在着色底下可读。 |
| 受击 | 1 帧白，然后一小火花。 | 禁止满屏闪。 |
| 架势击破 | 绿跪 + 击破帧金火花。 | 跪姿 HOLD 满 90 f。 |

黄 **仅** 在 hitbox 存活时存在。`hit_off` 已触发则黄立刻消失。

## 4. 敌人四招读法（HUD 关）

这四招必须在 Mid 距离、`hit_on` 之前就能叫出名。

| 招式 | 姿势（预警 telegraph） | 威胁形状 |
| --- | --- | --- |
| **Sweep** | 剑收到 **右肩**，躯干水平蓄力。红从 f1 起。蓄力 HOLD 满 **22 f**。 | 宽水平。后摇：刃收到左侧，胸口敞开，绿从后摇 f8 起。 |
| **Thrust** | 剑尖指向，肩正对，一步。红从 f1 起。朝向在 **预警 telegraph f10 锁定**。 | **直线**，不是扇面。后摇过度前倾，绿从后摇 f6 起。 |
| **Slam** | 双手举过顶。**红色地面圆半径 1.6 m 于 f8 出现**，脉动到落地。预警 telegraph **≥ 32 f**。 | 垂直砸。后摇：从地面拔起、膝弯，绿贯穿 **整段** 40 f。 |
| **DoubleSlash** | 第一击：从右上对角，红。间隙：一个 **小顿挫**（重心转移），仍红，然后左 → 右。 | 两击。不要把间隙做成正面可完整惩罚的开口。 |

若片段填不满预警 telegraph 时长，**HOLD 该姿势**。禁止缩短表格。

## 5. 玩家读法

| 招式 | 必须看清的内容 |
| --- | --- |
| Light1 | 右 → 左，适度蓄力，10 f 起手。 |
| Light2 | 左 → 右，接续，不是 Light1 的克隆。 |
| Light3 | 过顶对角，小步 0.4 m，后摇更长（挥空就是失误）。 |
| Heavy | 比轻击更大的蓄力，起手约 2×。Hyperarmor 用 debug 着色，不要新特效。 |
| ChargedHeavy | 蓄力时双手举过顶；允许走转。释放是下落砸击。 |
| JumpAttack | 下劈，落地进入 24 f 后摇。空中无 i-frame 着色。 |
| RunningAttack | 突进 1.2 m，窄突刺斩。 |
| DodgeRoll | 矮胶囊，位移 4.2 m，整段 32 f 可见。蓝仅在 f4–16。 |
| Guard | 前臂 / 武器 4 f 内抬起。无盾。 |
| Exhaust / GuardBreak | 喘息 / 敞开，偏绿的可罚态。不要看起来「准备好了」。 |
| Riposte | 踏入突刺。敌人保持绿跪。刺中 1 帧白。可选镜头推进 ≤ 20 f。 |

## 6. 镜头与特效禁止项（第一版冻结）

**禁止**

- 满屏暗角、压暗叠加、上下黑边、径向模糊、会盖住武器颜色的色散。
- 长震屏。受击轻点 ≤ 2 f、极小，或不要。Slam 可有短促下砸 ≤ 4 f，不是持续震动。
- 慢动作，除可选处决冻结 **≤ 8 f**（GDD 也允许轻微推进 ≤ 20 f）。不要把慢动作后处理做成默认。
- 比受击闪白 + 约 8 f 火花更长的受击特效。
- 贯穿后摇的刀光拖尾（会假造更长的判定）。
- 透明 / 消失的翻滚。
- 血液、血腥碎尸、肢解。
- 环境叙事、海报、会伪装 `#E03030` 的杂物。
- PBR 英雄着色、皮肤毛孔、布料模拟、独特头盔设定。
- 冲淡预警 telegraph 红的额外灯光。

**允许**

- 胶囊 / 棱柱 / 盒 / 剑条网格。
- 武器与地面圆上的无光照叠加发光。
- 1 帧白色材质覆盖。
- 可随 HUD 开关的 debug 着色。

## 7. 竞技场（仅美术）

平地，约 20 m，不要有挡住预警 telegraph 的掩体网格。中性冷灰地面，让红 / 黄 / 绿跳出来。若程序已拥有竞技场场景，不要再做场景 — 只提供他们可指定的材质（`game/assets/materials/arena_floor.tres`）。

## 8. 职责

美术拥有 `docs/art/**` 与 `game/assets/**`（网格、材质、AnimationLibrary、特效场景）。

美术 **不** 改 `game/*.gd`、玩家 / 敌人控制器场景或 `project.godot`。视觉作为实例挂在运行时角色下（见 `game/assets/README.md`）。
